# example

Example for Responsive Data Grid.

The default home is a catalog of scenario screens. Jump straight to one with:

```
flutter run --dart-define=DEMO_SCREEN=paged-fill-tab
```

`DEMO_SCREEN` values: `kitchen-sink`, `paged-fill-tab`, `paged-fill-tall`, `paged-fill-unbounded`, `paged-fill-groups`, `infinite-bounds`, `infinite-unbounded`.
