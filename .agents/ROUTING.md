# Skill routing

| Task | Skill |
| --- | --- |
| Open a GitHub PR | `rdg-open-pr` |
| GitHub PR exists / drop Copilot PR review | `rdg-pr-review-loop` |
| Spawned as security reviewer | `rdg-review-security` |
| Spawned as quality reviewer | `rdg-review-quality` |

Never assign `@copilot` as a reviewer.
